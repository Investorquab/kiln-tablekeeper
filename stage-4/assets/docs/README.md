# Tablekeeper visual asset pack

Copy this `assets/` folder into the Stage 4 folder:

```text
C:\Users\NEW\Desktop\kiln-tablekeeper\stage-4\assets\
```

Then have the Band Implementer read:

```text
stage-4/assets/docs/IMPLEMENTER-INSTRUCTIONS.md
stage-4/assets/docs/ASSET-MAP.md
```

The package contains local WebP venue photography, SVG illustrations, SVG icons and branding artwork. `generated-asset-board.png` is a design/provenance reference and is not required at runtime.
