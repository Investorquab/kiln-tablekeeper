# Asset provenance

These visual assets were created specifically for the Tablekeeper project during the design pass using AI image generation and custom-authored SVG artwork.

The bundled restaurant photography files are local derivatives of the project-specific generated visual board, resized/cropped and converted to web-friendly WebP for offline use. The SVG icons, illustrations, logo and favicon are custom project artwork created for this repository.

No runtime dependency on third-party stock-image hosting or remote image URLs is intended.

For the final hackathon README, describe the visual provenance accurately: the **visual assets were generated by the team**, while the **application code integration remains Band-produced work and should be traceable through the room log and git history**.
