## Visual asset provenance

The visual assets used by Tablekeeper were generated specifically for this project by the team using AI image generation plus custom-authored SVG artwork. They are bundled locally in the repository so the public clone and isolated judging environment do not depend on external image URLs.

The asset generation was a design/content step; the application code that integrates these assets into the Stage 4 experience is Band-produced work and is traceable through the submitted room log and git history.
